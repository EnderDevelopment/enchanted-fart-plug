# Gas Pass Minecraft Mod

Gas Pass is a Fabric Minecraft mod that adds a wearable armor enchantment. When armor with the Gas Pass enchantment is equipped, the player emits a comical burp-like sound and green gas particles every 10 seconds.

## Install

1. Install Minecraft 26.3.
2. Install Fabric Loader 0.20.1 or newer for Minecraft 26.3.
3. Install the matching Fabric API version.
4. Build or obtain the `gas_pass-1.0.0.jar` file.
5. Place the JAR file in the Minecraft `mods` folder.
6. Launch Minecraft with the Fabric profile.

Requirements:

- Minecraft 26.3
- Fabric Loader 0.20.1 or newer
- Fabric API
- Java 25 or newer

## Use

1. Obtain the Gas Pass enchantment through an enchanting table, an enchanted book, or a command.
2. Apply Gas Pass to a supported armor item.
3. Equip the enchanted armor in any armor slot.
4. After the enchantment is detected, the player emits a burp-like player sound and green gas particles once every 200 game ticks, or approximately every 10 seconds.
5. Remove all armor items with Gas Pass to stop the effect.

The enchantment has one level, supports armor items, and has an anvil cost of 2.
